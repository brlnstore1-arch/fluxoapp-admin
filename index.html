Configuração necessária
O painel está usando o App ID do Android. Você precisa registrar um Web App no Firebase para o painel funcionar.

Siga os passos abaixo:
1. Acesse o Firebase Console
Vá em console.firebase.google.com → Projeto fluxoapp-painel
2. Adicione um Web App
Clique em ⚙️ Configurações do projeto → Seus apps → Botão </> (Web)
3. Copie o firebaseConfig
Registre o app (nome: "Painel Admin") → copie o objeto firebaseConfig → cole no lugar indicado no código deste arquivo (linha ~530)
4. Crie o usuário admin
No Firebase Console → Authentication → Users → Adicionar usuário → informe email e senha do admin
5. Configure as Regras do Firestore
Firestore → Rules → cole as regras do arquivo firestore.rules → Publicar
